# almc-verifactu-wordpress-WooCommerce
ALMC VeriFactu - Official WordPress plugin that auto-submits WooCommerce invoices to the Spanish Tax Agency (AEAT) under the Verifactu electronic invoicing regulation (Real Decreto 1007/2023). HKDF-encrypted certificates, sandbox/production environments, HPOS-compatible. Backed by ALMC Security SaaS.
